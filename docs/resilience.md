# Resilience Patterns

This document describes the resilience patterns implemented in dagger-zig.

## Overview

The SDK implements several resilience patterns to ensure reliable CI/CD pipeline execution.

## Patterns

- Retry with exponential backoff
- Circuit breaker for GraphQL queries
- Timeout handling
- Graceful degradation
