# Type System

Documentation of the type system.

## Overview

The SDK uses comptime type generation for Dagger API types.

## Core Types

- `Container` - Container operations
- `Directory` - Directory operations
- `File` - File operations
- `Service` - Service container management
- `Secret` - Secret handling
- `CacheVolume` - Cache volume management

## Type Generation

Types are generated from the Dagger GraphQL schema.
